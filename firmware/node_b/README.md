# Firmware Node B (ESP32 – tủ 2 ngăn + hộc pin)

Phụ trách: TV3. Các việc: T15, T22, T23, T29.

Phần cứng: 3 × HX711 (cấp 3,3 V; 2 ngăn dụng cụ + 1 hộc pin ở GPIO 36/21), 3 × servo SG90 (LEDC 50 Hz; servo #3 ở GPIO 18), LED đỏ/xanh cho 2 ngăn và hộc pin (GPIO 19/23 qua điện trở 330 Ω), cảm biến DHT22 (GPIO 17). Phân bố chân: Bảng 6 trong báo cáo.
